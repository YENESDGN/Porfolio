# Görseller

Optimize edilmiş dosyalar buraya girer. DB yalnızca yolu tutar (/images/projects/x.webp).

| Klasör      | İçerik                                                   |
| ----------- | -------------------------------------------------------- |
| `profile/`  | Portre; `LandingPage` ve ilk `AboutSection` kullanır     |
| `projects/` | `<slug>-<n>.webp`, en fazla 1600 px genişlik; `-1` kapak |
| `tech/`     | Teknoloji işaretleri (SVG), kendi README'si var          |
| `social/`   | Navbar ikonları (SVG), kendi README'si var               |

Ekran görüntüleri projeler yerelde çalıştırılıp alındı, WebP olarak sıkıştırıldı.
